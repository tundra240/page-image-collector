Paste a page address. The app visibly scrolls through it, gathers the images that load, then lets you filter by type and save the ones you want.

Recent
  1. 1 Give it an address

    The scheme is optional — example.com works. A line under the box shows what will actually be used.

  2. 2 It scrolls the page for you

    A second window opens and scrolls to the bottom. That is what makes lazy-loaded images appear, so let it work.

  3. 3 Filter, then save

    Untick a format to hide it, click a card to deselect it, then write the rest straight into a folder you choose.

Everything stays on this machine — nothing is uploaded, and captured images are held in memory only until you save them. Images drawn to a <canvas> or generated by CSS cannot be captured as files, so a page can show pictures this finds nothing for.
