Page Image Collector

How to use it. To go back, click the title above.

  1. 1 Give it a page address

    Type or paste the address of the page holding the pictures you want. The https:// part is optional — example.com is enough, and so is example.com/gallery for one page within a site. Common slips in the address are corrected for you, and once you pause typing, a line underneath shows exactly which address will be used, so you can check it before starting.

    Local addresses work too, such as localhost:3000.

  2. 2 Decide how many to take

    Image cap stops the scan once it has that many pictures. The default of 500 suits almost every page. It is a safety limit rather than a target: pictures are held in memory until you save them, so a very large cap on a very image-heavy page can use a lot of it.

    Tick Auto cap to take everything the page has instead. The true total cannot be known in advance, because many pages only load pictures as you reach them — so while it runs, the count is shown with a ~ to say it is still an estimate. The final number is often a little lower, since some addresses turn out to be missing files or not pictures at all.

  3. 3 Press "Find images"

    A second browser window opens and scrolls down the page by itself. Let it work — that scrolling is what makes pictures load on pages that only fetch them as you scroll. It closes on its own when finished.

    Long pages take a while: the scan pauses at every step to give the page time to fetch the next set of pictures. The bar tracks how far down it has reached and how many it has found.

  4. 4 Filter by file type

    Show types lists one chip per format actually found, each with a count — for example WebP 12 · PNG 4 · JPEG 7. Untick a format to hide it. Hidden formats are excluded from saving as well, so you cannot accidentally save something you filtered out.

  5. 5 Choose the ones you want

    Everything starts selected. Click anywhere on a picture to deselect it — it greys out and fades, so what you are about to save is clear at a glance. Click it again to bring it back.

    Select all and Select none act only on what is currently visible, so a hidden format is left alone.

    Hovering a picture also offers two small buttons. One opens it on its own in a new tab. The other, {}, shows where on the page it came from and how large it was displayed there — and offers Show me on the page, which opens the original page again and highlights that exact picture in place. That is the quickest way to tell two near-identical pictures apart, or to see what something actually was.

    Give it a few seconds: the page has to load again before it can point at anything. If the page has changed since your scan, it will say so and point at roughly where the picture used to be rather than pretending it found it.

  6. 6 Save them

    Press Save selected images… and choose a folder. The files are written straight into it. Names are numbered by their position on the page — 001-, 002- — and the file extension always matches what the picture really is, which is not always what its address claimed.

    Saving needs Chrome or Edge. Firefox and Safari have no way for a page to write files into a folder you pick, so the button reports that instead.

Other things worth knowing

  • Starting over. Click the title at the top of the app. It clears the address and the results. Your cap and Auto cap settings are kept, since those are choices for the next scan. It does nothing while a scan is running.
  • Recent addresses. Pages you have scanned appear above the guide cards on the app's home screen. Click one to put it back in the box. Clear forgets them. They are the only thing remembered between uses, they never leave your machine, and the pictures themselves are never written anywhere you did not choose.
  • Everything is local. Nothing is uploaded, and no addresses or pictures are sent anywhere. The app is only reachable from this computer.

If something goes wrong

It found no pictures on a page that clearly has them
Some pages draw their pictures rather than loading them as files. There is no file to save in that case, so nothing can be collected. It is worth trying once more first, in case the page was simply slow.
Fewer pictures than expected
The cap counts every format together, so a page heavy in one of them can reach the limit before the others are reached. Raise the cap, or tick Auto cap.
"Image is no longer available"
Pictures are only held while the app stays open, and each new scan replaces the last set. Run the scan again, then save without starting another scan in between.
"A scan is already running"
Only one scan happens at a time — possibly one started in another tab. Wait for it to finish; the bar shows how far along it is.
The page took too long to load
Open the address in a normal tab first to check it works. If it loads but slowly, try again — the time limit applies to each attempt, not to the total.
The app itself will not open
It only runs while its launcher is open. If you closed that window, start it again.
